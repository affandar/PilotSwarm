### `cms_provider_check_turn` — body modified (baseline: 0053)

The admission gate now resolves the same effective model precedence as session
execution: an explicit turn override, the session's stored model, the owner's
personal default, then the cluster default. This prevents sessions intentionally
created with a null model from being parked as `no_provider` before the worker
can apply the configured default.

```diff
-    -- The catalog row is authoritative for the model, exactly as the turn
-    -- runtime treats it; the argument is only the turn's own override.
-    v_ref := COALESCE(NULLIF(BTRIM(COALESCE(p_model, '')), ''), v_sess.model);
+    SELECT COALESCE(
+               NULLIF(BTRIM(COALESCE(p_model, '')), ''),
+               NULLIF(BTRIM(COALESCE(v_sess.model, '')), ''),
+               NULLIF(BTRIM(COALESCE(u.default_model, '')), ''),
+               NULLIF(BTRIM(COALESCE(cs.default_model, '')), ''))
+      INTO v_ref
+      FROM SCHEMA.provider_cluster_settings cs
+      LEFT JOIN SCHEMA.users u ON u.user_id = v_owner
+     WHERE cs.singleton;
```
