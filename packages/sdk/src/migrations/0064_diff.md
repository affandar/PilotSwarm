# Diff for migration 0064

Migration file: `cms-migrations.ts` — `migration_0064_canvas_kv`

The canvas KV store: shared, durable, per-key state for interactive canvas
apps (`docs/proposals/interactive-canvas-apps.md` Part C), plus the
per-canvas write policy (Part D).

## Table Changes

### `session_canvases`

```diff
+ kv_access   TEXT  NOT NULL DEFAULT 'owner' CHECK (kv_access IN ('owner','readers','link'))
+ kv_manifest JSONB
```

`kv_access` is the owner's policy for who may write the canvas KV.
`kv_manifest` caches the drawn document's `CANVAS-APP-MANIFEST` `kv` block
(`{ "write": "owner" | "viewers", "shared": [...] }`) so a write never
re-reads the document.

### `canvas_kv` — new

```sql
canvas_kv (
  session_id TEXT     NOT NULL REFERENCES sessions(session_id) ON DELETE CASCADE,
  slot       SMALLINT NOT NULL CHECK (slot BETWEEN 1 AND 5),
  key        TEXT     NOT NULL,
  value      JSONB    NOT NULL,      -- the envelope { v, by, at }
  rev        BIGINT   NOT NULL DEFAULT 1,
  deleted_at TIMESTAMPTZ,            -- tombstone; rev still advances
  updated_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  PRIMARY KEY (session_id, slot, key)
)
```

Why the CMS and not the facts table the proposal first named: the facts
store can be a different database (HorizonDB), and the write must be atomic
with its `NOTIFY` on the CMS connection. Deleting the session cascades.

## Function Changes

### `cms_canvas_kv_write` — new

`(session_id, slot, key, value | NULL, if_match | NULL, max_keys, max_bytes,
max_value_bytes, schema) → (status, rev, size_bytes)`.

One statement: locks the row, applies the compare-and-swap (`0` = the key
must not be live, `N` = the live rev must be `N`), the per-value cap, the
per-canvas key and byte budgets, upserts (a `NULL` value tombstones), and
`pg_notify('pilotswarm_canvas_live', {kind:"kv", key, rev, op, value?})`.
The value rides the ping when the envelope is under 7000 bytes; otherwise
the ping is a pointer. Statuses: `written | deleted | not_found | conflict |
too_large | quota_keys | quota_bytes`.

### `cms_canvas_kv_get`, `cms_canvas_kv_list`, `cms_canvas_kv_stats` — new

Live rows only. `list` is prefix-filtered, key-ordered, cursor = last key,
page ≤ 200.

### `cms_set_canvas_kv_access`, `cms_set_canvas_kv_manifest`, `cms_get_canvas_kv_settings` — new

Upsert the `session_canvases` row when the canvas was never drawn (an owner
may set the policy before the first draw). `CANVAS_KV_BAD_ACCESS` on an
unknown policy value.
