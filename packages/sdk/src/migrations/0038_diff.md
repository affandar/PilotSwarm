# Diff for migration 0038

Migration file: `cms-migrations.ts` — `migration_0038_agent_packages`

Registry for user-uploadable agent packages (docs/proposals/agent-packages.md).
Everything in this migration is new — five tables, one index, seventeen
functions. No existing table or function is touched, so the migration is a
single transactional `sql` entry (no `steps` shape needed).

## Table Changes

### `agent_sources` — new table

```sql
CREATE TABLE IF NOT EXISTS SCHEMA.agent_sources (
    source_id        TEXT PRIMARY KEY,
    kind             TEXT NOT NULL CHECK (kind IN ('github', 'ado', 'url', 'upload')),
    repo_url         TEXT,
    ref              TEXT,
    path             TEXT,
    url              TEXT,
    auth_token       TEXT,
    auto_sync        BOOLEAN NOT NULL DEFAULT FALSE,
    last_sync_at     TIMESTAMPTZ,
    last_sync_status TEXT,
    last_sync_error  TEXT,
    last_commit_sha  TEXT,
    owner_provider   TEXT,
    owner_subject    TEXT,
    created_by       TEXT,
    created_at       TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

`auth_token` follows the `users.github_copilot_key` posture (migration 0010):
list/get procs project only `(auth_token IS NOT NULL)`; the raw read is a
separate internal-only proc. Ownership identity is `(owner_provider,
owner_subject)` — the same principal pair the session procs use (BTRIM'd on
write and compare) — with `created_by` kept as a display label only.

### `agent_packages` — new table

```sql
CREATE TABLE IF NOT EXISTS SCHEMA.agent_packages (
    package_id        TEXT PRIMARY KEY,
    source_id         TEXT REFERENCES SCHEMA.agent_sources(source_id) ON DELETE SET NULL,
    name              TEXT NOT NULL UNIQUE,
    scope             TEXT NOT NULL CHECK (scope IN ('shared', 'user')),
    owner_provider    TEXT,
    owner_subject     TEXT,
    enabled           BOOLEAN NOT NULL DEFAULT TRUE,
    active_version_id TEXT,
    created_by        TEXT,
    created_at        TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

Ownership is the `(owner_provider, owner_subject)` principal pair (no FK to
`users` — anonymous / no-auth deployments have no user rows; the anonymous
role is admin-equivalent anyway). `active_version_id` is app-maintained
(circular FK with versions avoided deliberately).

### `agent_package_versions` — new table

```sql
CREATE TABLE IF NOT EXISTS SCHEMA.agent_package_versions (
    version_id        TEXT PRIMARY KEY,
    package_id        TEXT NOT NULL REFERENCES SCHEMA.agent_packages(package_id) ON DELETE CASCADE,
    semver            TEXT NOT NULL,
    sha256            TEXT NOT NULL,
    size_bytes        BIGINT NOT NULL,
    artifact_filename TEXT NOT NULL,
    commit_sha        TEXT,
    manifest          JSONB NOT NULL,
    created_by        TEXT,
    created_at        TIMESTAMPTZ NOT NULL DEFAULT now(),
    UNIQUE (package_id, semver)
);
```

`(package_id, semver)` uniqueness is the immutability anchor: same-semver
republish with different content is rejected by `cms_publish_agent_package`.

### `agent_registry_state` — new table (singleton)

```sql
CREATE TABLE IF NOT EXISTS SCHEMA.agent_registry_state (
    id         INTEGER PRIMARY KEY CHECK (id = 1),
    epoch      BIGINT NOT NULL DEFAULT 1,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
INSERT INTO SCHEMA.agent_registry_state (id) VALUES (1) ON CONFLICT (id) DO NOTHING;
```

Workers poll `epoch` (single-row read) to converge on registry changes without
restarts. Every mutating proc that changes what workers should run calls
`cms_agent_registry_bump()`.

### `agent_worker_state` — new table

```sql
CREATE TABLE IF NOT EXISTS SCHEMA.agent_worker_state (
    worker_node_id TEXT PRIMARY KEY,
    epoch          BIGINT NOT NULL DEFAULT 0,
    installed      JSONB NOT NULL DEFAULT '{}'::jsonb,
    updated_at     TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

The fleet-truth channel: workers upsert after each install pass; the portal
renders fleet adoption from it. First worker registration table in the CMS.

## New Indexes

```sql
CREATE INDEX IF NOT EXISTS agent_packages_owner_idx ON SCHEMA.agent_packages (owner_provider, owner_subject);
```

## Function Changes

All functions are new.

### Epoch

```diff
+ cms_agent_registry_epoch() RETURNS BIGINT
+ cms_agent_registry_bump() RETURNS BIGINT
```

Read / increment the singleton epoch. `bump` is called by every mutating proc
below that changes worker-visible state (publish, scope, enabled, pin, delete).

### Sources

```diff
+ cms_register_agent_source(p_source_id, p_kind, p_repo_url, p_ref, p_path, p_url,
+     p_auth_token, p_auto_sync, p_owner_provider, p_owner_subject, p_created_by) RETURNS VOID
+ cms_list_agent_sources(p_viewer_provider, p_viewer_subject, p_is_admin)
+     RETURNS TABLE(... auth_token_set BOOLEAN ...)
+ cms_get_agent_source(p_source_id) RETURNS TABLE(... auth_token_set BOOLEAN ...)
+ cms_get_agent_source_token(p_source_id) RETURNS TEXT            -- internal-only
+ cms_update_agent_source_sync(p_source_id, p_status, p_error, p_commit_sha) RETURNS VOID
+ cms_delete_agent_source(p_source_id, p_actor_provider, p_actor_subject, p_is_admin) RETURNS VOID
```

Source visibility is creator-or-admin. `cms_get_agent_source_token` must never
be exposed through the public management API. Sync-status updates do not bump
the epoch (they change nothing workers run).

### Publish

```diff
+ cms_publish_agent_package(p_package_id, p_version_id, p_name, p_scope,
+     p_owner_provider, p_owner_subject, p_source_id, p_semver, p_sha256,
+     p_size_bytes, p_artifact_filename, p_commit_sha, p_manifest,
+     p_created_by, p_is_admin)
+     RETURNS TABLE(status TEXT, package_id TEXT, version_id TEXT)
```

The atomic heart. Row-locks the package by name (`FOR UPDATE`), then:
new package → insert package + version, activate, bump, `'published'`;
existing package → creator-or-admin check (`AGENT_PACKAGE_FORBIDDEN`), then
identical `(semver, sha256)` → `'noop'`; same semver different sha →
`AGENT_PACKAGE_SEMVER_CONFLICT` (immutable versions, no replace); otherwise
insert version, activate it, bump. Publishing always activates the published
version; backfilling an older semver is publish-then-pin.

### Package reads

```diff
+ cms_list_agent_packages(p_viewer_provider, p_viewer_subject, p_is_admin) RETURNS TABLE(...)
+ cms_get_agent_package(p_name, p_viewer_provider, p_viewer_subject, p_is_admin) RETURNS TABLE(...)
+ cms_get_agent_packages_install_manifest() RETURNS TABLE(...)
```

The two viewer-filtered reads are THE user-scope privacy boundary:
`scope = 'shared' OR admin OR owner`. `list` joins the active version;
`get` returns one row per version (history), newest first. The install
manifest is worker-facing (trusted infrastructure) — enabled packages joined
to their active version, no viewer filter by design.

### Package mutations

```diff
+ cms_agent_package_authz(p_name, p_actor_provider, p_actor_subject, p_is_admin)
+     RETURNS SCHEMA.agent_packages
+ cms_set_agent_package_scope(p_name, p_scope, p_actor_provider, p_actor_subject, p_is_admin) RETURNS VOID
+ cms_set_agent_package_enabled(p_name, p_enabled, p_actor_provider, p_actor_subject, p_is_admin) RETURNS VOID
+ cms_pin_agent_package_version(p_name, p_semver, p_actor_provider, p_actor_subject, p_is_admin) RETURNS VOID
+ cms_delete_agent_package(p_name, p_actor_provider, p_actor_subject, p_is_admin)
+     RETURNS TABLE(artifact_filename TEXT)
```

`cms_agent_package_authz` is the shared guard: `FOR UPDATE` row lock +
`AGENT_PACKAGE_NOT_FOUND` / `AGENT_PACKAGE_FORBIDDEN` (creator-or-admin).
Every mutation calls it, then bumps the epoch. `delete` returns the artifact
filenames of all deleted versions so the caller can clean the artifact store
after commit.

### Worker fleet state

```diff
+ cms_upsert_agent_worker_state(p_worker_node_id, p_epoch, p_installed) RETURNS VOID
+ cms_list_agent_worker_state() RETURNS TABLE(worker_node_id, epoch, installed, updated_at)
```

No epoch bump (worker reports are observations, not registry changes).
