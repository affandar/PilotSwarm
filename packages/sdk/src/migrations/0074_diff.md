## Function Changes

All functions are new (no previous stored-procedure baseline).

```diff
+ cms_live_available() RETURNS BOOLEAN
+ cms_get_live(p_session TEXT, p_topics TEXT[] DEFAULT NULL)
+   RETURNS TABLE(topic TEXT, seq BIGINT, payload JSONB, updated_by TEXT,
+                 updated_at TIMESTAMPTZ, size_bytes INTEGER)
+ cms_publish_live(p_session TEXT, p_topic TEXT, p_data JSONB,
+                  p_kind TEXT, p_writer TEXT, p_max_bytes INTEGER)
+   RETURNS JSONB
```

- Availability is schema-scoped; an older deployment without these functions
  degrades to no live state rather than breaking the durable path.
- Reads filter by session and optional topic array.
- Publishing validates object payloads and supports snapshot replacement,
  RFC 7386 merge patches, and non-retained signals.
- The upsert composes patches atomically and increments the per-topic cursor.
  Size refusal leaves both row and cursor unchanged and sends no notification.
- PostgreSQL NOTIFY is performed in the same statement/transaction as the
  write. Envelopes larger than 7,900 bytes send a pointer, not the body.
- Retained JSON is capped at 256 KiB. No durable transcript, facts, or
  orchestration state is added or modified.
