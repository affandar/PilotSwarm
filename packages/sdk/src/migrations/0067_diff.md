## Function Changes

### `cms_provider_update_shared_credential` — new

```diff
+ cms_provider_update_shared_credential(
+     p_name TEXT, p_secret JSONB, p_actor BIGINT, p_is_admin BOOLEAN
+ ) RETURNS TABLE(name TEXT, type_id TEXT, class TEXT, owner_user_id BIGINT)
```

Rotates the credential of a SHARED provider. Admin-only, through
`cms_provider_assert_manage` — the same gate every other shared mutation uses,
so the refusals match exactly: a non-admin gets `PROVIDER_FORBIDDEN`, and a
personal name reads as `PROVIDER_NOT_FOUND` even to an admin (this cannot be
used to discover that someone's provider exists). Shared providers had no
rotation before; an expired cluster key meant delete-and-recreate, which drops
the cluster-default flag, the allowance, any hold, the system-use routing and
the usage history.

A provider seeded from the deployment's model-providers file holds a POINTER to
its secret (`ref: "env:AZURE_KEY"`, `source: "config-file"`), not the secret —
the arrangement under which no key is ever copied into the database. Rotating it
here would replace the pointer with a literal value and silently detach the
provider from its environment variable, so the shared op refuses those with
`PROVIDER_FORBIDDEN` and names the variable to rotate instead.

### `cms_provider_update_personal_credential` — replaced

Both paths now share one write shape:

```diff
-    SET secret_ref = CASE ... apiVersion carry-forward ... END,
+    SET secret_ref = (COALESCE(pi.secret_ref, '{}'::jsonb)
+                        - 'value' - 'kind' - 'token' - 'apiKey' - 'githubToken' - 'key' - 'ref' - 'source')
+                     || p_secret,
         updated_at = now()
```

Strip-then-merge. Every stored field survives a rotation unless the caller
restates it — 0066 carried `apiVersion` forward specifically, but the shape of
the bug was general: a one-field form replacing a whole document. The strip
is load-bearing: merging naively kept the OLD secret in the blob under the key
it was created with (`token` / `apiKey` / `githubToken`) beside the new
`value` — a rotated key that had not actually retired.
