The breakdown reader retains migration 0061's ledger filters and provider epoch
bound. It groups inaccessible session IDs into `(private sessions)` **before**
the limit. Agent bindings belonging to other users are grouped as
`(other users agents)`; the historical ledger does not reliably identify the
current package ACL. Own and system labels remain. No tokens are filtered out.

The agent pivot retains migration 0071's time windows, numeric fields and model
series, with the same pre-aggregation agent-label projection. The summary and
per-user accounting readers are unchanged.

The paused-session reader keeps the existing bounded operational window and
returns only accessible rows from it. It is not a fleet spend filter.
