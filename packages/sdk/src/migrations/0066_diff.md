## Function Changes

### `cms_provider_update_personal_credential` — replaced

```diff
  UPDATE provider_instances pi
-    SET secret_ref = p_secret
+    SET secret_ref = CASE
+            WHEN p_secret ? 'apiVersion' THEN p_secret
+            WHEN pi.secret_ref ? 'apiVersion'
+                THEN p_secret || jsonb_build_object('apiVersion', pi.secret_ref -> 'apiVersion')
+            ELSE p_secret
+        END,
+        updated_at = now()
   WHERE pi.name = p_name AND pi.class = 'personal' AND pi.owner_user_id = p_actor
```

0065 replaced the whole `secret_ref` blob with what the caller sent. The caller
is a credential form and sends one field, so a pinned `apiVersion` was dropped
on every rotation — `provider-catalog` reads `secret_ref.apiVersion` and
otherwise falls back to the type default, so an azure-openai provider pinned to
a version silently moved off it. A caller who states an `apiVersion` still wins.

`updated_at` was never set by 0065, so a rotation left `created_at ==
updated_at` and no trace of the change on the row.

Superseded by 0067, which generalises the carry-forward to every stored field.
